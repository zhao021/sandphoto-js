# 照片打印版排版

一个浏览器端照片排版工具，用来把证件照或胶片照片按指定尺寸排到冲印纸张上，并导出可下载图片。

## 在线页面

已部署到 GitHub Pages：

[https://zhao021.github.io/sandphoto-js/](https://zhao021.github.io/sandphoto-js/)

## 这版优化

- 优化裁剪线：保留单一贯穿式虚线，横竖线会沿照片边界延伸到整张纸面，方便后续裁切。
- 优化排布细节：改进张数排版策略，例如 8 张照片会优先使用更整齐的 4x2 排布，避免 3x3 缺一块的效果。
- 精简规格选项：保留常用照片尺寸和纸张尺寸，去掉重复、低频和容易误导的选项。
- 调整输出样式：纸面使用白色底，边界更清晰，整体界面更适合打印前检查。

## 功能

- 支持单张照片和多张照片上传。
- 支持常用照片尺寸、冲印纸张、照片张数、排版方向和间距设置。
- 支持蓝色、黑色、灰色裁剪虚线。
- 图片处理全部在浏览器本地完成，不上传照片。

## 本地使用

直接在浏览器打开 `index.html`，或用本地静态服务器运行项目。
