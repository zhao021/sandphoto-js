# 照片排版工具

一个浏览器端照片排版工具，用来把证件照或胶片照片按指定尺寸排到冲印纸张上，并导出可下载图片。

## 功能

- 支持单张照片和多张照片上传。
- 支持常用照片尺寸、冲印纸张、照片张数、排版方向和间距设置。
- 使用单一虚线贯穿照片边界，便于裁切。
- 输出纸面为白色，边界清晰。
- 图片处理全部在浏览器本地完成，不上传照片。

## 文件结构

```text
.

├── index.html          # 主页面入口

├── phototypes.js       # 照片和纸张规格数据
├── styles.css          # 界面样式
├── ui-generator.js     # 中文界面生成器
├── LICENSE
```

## 使用

直接在浏览器打开 `index.html`，或用本地静态服务器运行项目。
